# Privacy Policy

**Perchance Image Downloader** does not collect, store, or transmit any personal data.

## Data Handling

- **Settings** (theme preference, folder name, preview size) are stored locally via `chrome.storage.local` and never leave your device.
- **Downloaded images** are saved directly to your local filesystem using the `downloads` API.
- **No analytics, no tracking, no external servers** — this extension makes no network requests to any third-party service.

## Permissions

| Permission | Purpose |
|------------|---------|
| `downloads` | Save images to your disk |
| `storage` | Remember your preferences locally |
| `contextMenus` | Right-click download option |
| `activeTab` | Communicate with the active tab |
| `webNavigation` | Find images across iframes |

All permissions are used solely for the extension's core functionality. No data is shared with anyone.
